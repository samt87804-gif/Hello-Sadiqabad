## 2. Visitor Flows
**Find a business:** Home → type in hero search (autocomplete) or tap a category/quick link → Search results (filters + sort) → tap card → Business profile → tap **Call** (opens `tel:`; event `call` tracked) / **WhatsApp** (`wa.me`, event `whatsapp`) / **Directions** (Google Maps URL, event `directions`) / **Share** (Web Share API or copy link, event `share`).
**Open now:** computed on the client from `opening_hours` + Pakistan time (Asia/Karachi). Badge shows Open / Closed / Open 24 hours / Hours not listed.
**Language switch:** header menu → English / اردو → text and direction flip instantly; "Show Urdu hints" toggle exists in the same menu (English mode only).
**Favorites:** heart icon on cards/profile toggles save in `hs_favorites`; Favorites page lists them (fetch by ids). **Recently viewed** stored in `hs_recent` (max 10) and shown on Home and Favorites.
**Near me:** Search/Map "Near me" asks browser location permission; if denied, show a message and continue without distance.
**Send Inquiry** (only if plan feature `inquiry`): modal (name, phone, message + hidden honeypot) → Edge Function `submit-inquiry` → success toast; errors: validation, rate limit ("Please try again later").
**Write Review:** modal (name, 1–5 stars, comment) → `submit-review` → "Thanks, your review will appear after approval".
**Suggest correction / Report / Broken image / Claim this business:** modals → `submit-suggestion` with `type` (`correction`, `phone_suggestion`, `report`, `broken_image`, `claim`).
**Add Business:** form (name en/ur, category, area, phone, address, optional WhatsApp, description, contact name/phone) → `submit-suggestion` type `new_business` → moderation queue.
**Offers:** list active offers (`status='active'` and now between `valid_from` and `valid_to`) → tap → business profile.
**Emergency:** list from `emergency_contacts`; each row has a big Call button; data cached for offline.

## 3. Authentication Flows
1. **Login:** email + password → on success load `profile`; if `must_change_password` → `/change-password`; else redirect by role: `super_admin`/`staff` → `/admin`, `owner` → `/owner`. If account inactive (staff) show "Account disabled".
2. **First login (admin-created account):** admin gives temporary password → user logs in → must set new password (min 8 chars, confirm) → `must_change_password=false`.
3. **Forgot password:** enter email → Supabase sends link → `/reset-password` → set new password → login.
4. **Logout:** clears session, returns to `/`.
5. **Guards:** unauthenticated access to protected route → `/login?next=<path>`; wrong role → friendly "Not allowed" page with a link home.

## 4. Owner Flows
- **Dashboard:** cards for each owned listing (status badge, plan + days to expiry, views/calls last 30 days), counters (new inquiries, pending reviews to reply, unread notifications). If no listing: explain how to get one (Add Business / Claim).
- **Edit listing:** tabs Basic · Contact · Location · Hours · Media · Social · Services/Tags · Preview. Plan limits shown (e.g. "3 of 5 photos"); locked features show a lock with "Upgrade". Save draft → "Submit for approval" (`pending_approval`). Changes to a *published* listing: allowed fields save directly and are logged; (admin may require re-approval via setting `owner_edits_require_approval`, default off).
- **Offers:** list + create/edit modal (title, description, image URL, valid from/to); limit by plan; expired offers auto-marked.
- **Reviews:** approved reviews with a Reply box (500 chars, once; editable by owner).
- **Inquiries:** inbox (new/read/handled); tapping marks read; "Call back" button uses `tel:`.
- **Analytics:** 7/30/90-day toggle; chart of views, calls, WhatsApp, directions, shares per day; totals.
- **Plan:** plan comparison; "Request upgrade" → `plan_upgrade` submission → toast "Our team will contact you".
- **Notifications:** created by DB triggers (new inquiry, review approved/rejected, listing approved/rejected, plan expiring in 7 days, claim approved).

## 5. Admin / Staff Flows
Each tab only appears if the user has the permission (see PRD 4.5).

## 6. UI States (apply everywhere)
- **Loading:** skeletons for lists/cards; button spinners on submit.
- **Empty:** `EmptyState` with icon, message (both languages) and a next action.
- **Error:** `ErrorState` with retry; `ErrorBoundary` for crashes; "Database not configured" if Supabase env is missing.
- **Success/Failure:** `Toast` (bottom, auto-dismiss) for actions.
- **Offline:** banner "You are offline"; Emergency page keeps working.
- **Forms:** inline validation messages in the current language, disabled submit while pending, no double submit.
- **Destructive actions:** `ConfirmDialog` before delete/suspend/archive.

## 7. Permission Matrix (summary)
Visitor: read public data, write via Edge Functions only. Owner: own business rows (limited columns), own offers/reviews replies/inquiries/notifications. Staff: per permission. Super admin: all. RLS enforces each rule (see `05_Backend_Schema.md` §RLS).
